# 캠퍼스 리마켓

학생 중고거래, 학교생활, 사장·매니저 센터, 관리자 화면을 하나의 Spring Boot 앱에서 제공합니다. IntelliJ에서는 `build.gradle`과 `src`가 있는 이 폴더를 열고 Gradle JVM을 JDK 25로 선택하세요. 실행 클래스는 `com.campus.remarket.CampusApplication`입니다.

## 처음 열어 볼 파일

| 화면 | 메인 HTML | 주소 |
| --- | --- | --- |
| 학생 | [student.html](src/main/resources/templates/pages/student.html) | `/sales/selectAll` |
| 사장·매니저 | [owner.html](src/main/resources/templates/pages/owner.html) | `/owner/` |
| 관리자 | [admin.html](src/main/resources/templates/pages/admin.html) | `/admin/` |

화면 세 개를 여는 코드는 [PortalPageController.java](src/main/java/com/campus/remarket/controller/PortalPageController.java)에 있습니다. 기본 기능과 개선점, DB 연결 방식, 게시판 CRUD와 역할별 REST 요청 예시는 [팀원용 코드 설명서](docs/코드와-API.md)에 정리했습니다.

## Docker로 실행

Docker Compose에서 MySQL 8.4와 앱을 함께 실행할 수 있습니다. PowerShell에서 프로젝트 폴더로 이동한 뒤 환경설정 파일을 복사합니다.

```powershell
Copy-Item .env.example .env
```

`.env`의 `CAMPUS_DB_PASSWORD`와 `MYSQL_ROOT_PASSWORD`에 서로 다른 비밀번호를 입력합니다. 학생 회원가입에 사용할 학교 이메일 인증을 위해 `SMTP_HOST`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `MAIL_FROM`도 메일 서비스 설정에 맞게 입력하세요. 기본 메일 연결은 587번 포트와 STARTTLS를 사용합니다.

```powershell
docker compose up --build -d
docker compose logs -f app
```

| 화면 | 기본 로컬 주소 |
| --- | --- |
| 학생 마켓 | http://localhost:8080/sales/selectAll |
| 학교 달력 | http://localhost:8080/sales/selectAll#life/calendar |
| 사장·매니저 | http://localhost:8080/owner/ |
| 관리자 | http://localhost:8080/admin/ |

회원, 거래, 학생 행사는 `mysql_data` 볼륨에 저장하고 업로드한 사진은 `campus_uploads` 볼륨에 저장합니다. `docker compose down` 이후 같은 프로젝트에서 `docker compose up -d`로 다시 시작할 수 있습니다. `down -v`는 볼륨과 그 안의 데이터를 삭제합니다. 기존 MySQL이 PC의 3306번을 사용한다면 `.env`에서 `CAMPUS_MYSQL_PORT`를 다른 포트로 지정하세요.

## IntelliJ 또는 Gradle로 실행

독립 MySQL 8.4 서버를 사용하거나, 위 설정 후 `docker compose up -d db`로 DB만 실행합니다. 독립 서버를 처음 준비하는 경우 MySQL 관리자로 아래 SQL을 실행합니다. 두 번째 문장이 출력한 비밀번호를 복사해 앱의 `CAMPUS_DB_PASSWORD`에 설정하세요.

```sql
CREATE DATABASE campus_remarket CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;
CREATE USER 'campus'@'localhost' IDENTIFIED BY RANDOM PASSWORD;
GRANT ALL PRIVILEGES ON campus_remarket.* TO 'campus'@'localhost';
```

PowerShell에서 아래 환경변수를 설정합니다. IntelliJ를 사용한다면 실행 구성의 환경변수에 같은 값을 입력하세요. Compose의 `.env`는 Docker Compose가 읽는 파일입니다.

```powershell
$env:CAMPUS_DB_URL = 'jdbc:mysql://localhost:3306/campus_remarket?connectionTimeZone=%2B09:00&forceConnectionTimeZoneToSession=true'
$env:CAMPUS_DB_USER = 'campus'
$env:CAMPUS_DB_PASSWORD = [Net.NetworkCredential]::new('', (Read-Host 'MySQL 비밀번호' -AsSecureString)).Password
.\gradlew.bat bootRun
```

Gradle 래퍼가 프로젝트에서 지정한 Gradle 버전을 내려받습니다. 전체 빌드와 회귀 테스트는 `.\gradlew.bat build`로 실행합니다. 자동 테스트는 테스트 전용 H2와 예시 계정을 사용합니다. 배포 JAR는 `build/libs/`에 생성됩니다.

## 데이터 초기화와 기존 자료

서버는 `spring.sql.init.mode=always`로 테이블을 준비하고 JPA로 회원 스키마를 검증합니다. 새 DB에는 가입과 게시판에 필요한 학교·분류가 등록됩니다. 회원 계정, 상품, 주문, 학생 행사는 사용자가 등록하면서 생깁니다.

이전 SQL의 `GENERATED BY DEFAULT AS IDENTITY`는 MySQL에서 구문 오류를 일으켰고, 예시 계정 `demo-buyer`를 넣는 `data.sql`은 두 번째 실행 시 기본 키와 충돌했습니다. 현재 스키마는 MySQL의 `AUTO_INCREMENT`를 사용하며, 테이블을 처음 만들 때 인덱스를 함께 생성합니다. 기존 파일형 H2 DB에 실제 자료가 있다면 원본 DB를 닫고 복사본과 **새 빈 MySQL DB**를 준비한 뒤 이관 안내를 따르세요. [H2 자료 이관 안내](tools/H2-이관.md)

새 DB에서 학생과 사장은 회원가입 화면을 이용하고, 매니저는 사장이 센터에서 발급합니다. 첫 관리자 계정은 운영 담당자가 직접 등록할 수 있습니다. 아래 명령은 암호를 대화형으로 입력받아 BCrypt 해시를 출력합니다.

```powershell
docker run --rm -it httpd:2.4-alpine htpasswd -nBC 12 campusadmin
docker compose exec db mysql -u campus -p campus_remarket
```

MySQL에서 아래 예문의 해시 자리에 앞 명령이 출력한 `campusadmin:` 뒤의 BCrypt 문자열을 입력합니다. 운영 담당자의 이메일로 바꾸면 계정 찾기에도 사용할 수 있습니다.

```sql
SET @admin_hash = '<BCrypt 해시>';
INSERT INTO member (login_id, account_key, password, name, email, role, created_at, withdrawn)
SELECT 'campusadmin', 'staff:campusadmin', @admin_hash, '운영 관리자', 'admin@example.org',
       'ADMIN', CURRENT_TIMESTAMP(6), FALSE
WHERE @admin_hash REGEXP '^[$]2[aby][$][0-9]{2}[$][./A-Za-z0-9]{53}$';
```

## 공개 HTTPS

공개 서버를 사용할 때는 도메인의 DNS를 서버 IP로 연결하고 80·443 포트를 열어 둡니다. `.env`의 `CAMPUS_DOMAIN`에 호스트 이름을 입력한 뒤 `docker compose --profile https up -d --build`를 실행하면 Caddy가 인증서를 발급하고 요청을 앱에 전달합니다. 배포 서비스가 HTTPS와 기본 도메인을 제공하는 경우에는 앱에 외부 MySQL 연결 정보를 환경변수로 설정하고 업로드 경로 `/var/lib/campus/uploads`에 영구 저장소를 연결하세요.

지도에 사용할 키는 `.env.example`에서 변수 이름을 확인할 수 있습니다. Git에는 Gradle 래퍼와 소스, 실행 예시를 포함하며 실제 비밀번호와 키는 실행 환경에서 설정합니다.
